当前桥使用360个1°bin，窄道远墙可能不足8个真实墙内点。测试中0.95m宽通道的8m前墙在360bin下仍返回未知，1440个真实几何射线才提供足够支持。扩大上限没有增加角分辨率，也不保证起点就能可靠观察远墙。

桥的 `at_ms` 是**整圈发布时刻**，不是逐点采集时间；当前 `LidarSample.captured_at` 也由发布时钟生成。速度估计、延迟与去畸变仍需如实计入整圈采集的时间不确定性，不能把该字段写成已经获得逐束采集时刻。当前完整扫描格式校验不等于整圈/包间时限已经认证。

## 斑马线停车目标

初稿PDF p2 §2.1要求：发车→人行道线前停3秒→按图绕两桶→红绿灯→终点；p3说明人行道位置在对应区域内随机。p5 §2.4.2(3)对线前不足3秒、压线或越过后停车、未停车分别罚10/20/30秒。规则未给出统一的“车头距近沿N厘米”，目标应由可观测近沿和车辆误差余量生成。[规则核对](赛项三规则与工程差距.md)

斑马线语义由有效YOLO结果准入，米制近沿、方向及误差由经验证的地面几何提供。识别框存在不等于距离有效；水平雷达的前墙、两侧墙或单束回波不能替代地面白条近沿。

[`online_mission.rs`](../crates/robot-core/src/online_mission.rs) 已有在线目标接口：在观测近沿中点/穿越方向坐标系中，车体参考点的停车目标为

`目标X = −车体前向长度 − 线前停车间隙 − 区域几何误差`

其中区域误差包含位置误差和航向误差引起的区域角点位移。完整车体还必须处于保守近沿之前；车头外参、前后悬、转向后的最外轮胎、测距误差和定位误差都要计入。既有横向尺量17cm只支持当前侧向参考，不是完整车身足迹标定。[车辆几何来源](车辆尺寸与几何来源.md)

`ElementObservation/ElementFrame` 保留真实来源、位置/方向/宽深、误差、源时刻与身份。`Crosswalk`使用近沿；`StopLine`在现接口中表示灯前**停车区域**，其远沿才是灯任务禁越线，不能混用。[元素接口](../crates/robot-core/src/local_world.rs)

## 实时距离与PWM曲线

每拍先求完整车体到目标边界的间隙下界，扣除所需线前间隙和几何误差，得到可用运动预算。再用真实运动上界检查当前PWM、降档响应、通信/控制/ESC延迟，以及1500后的全部滑行与转向扫掠。

可使用已验证的滑停上界模型：

`所需距离 = 延迟期间行程上界 + 中性滑行行程上界 + 剩余误差余量`

滑行上界须取当前速度、实际采用的PWM历史、电池/地面/载荷和转向状态对应的已验范围。速度不能因PWM降低而立即改写成较小值；源几何未投影到当前时刻时，要把源年龄对应的运动计入。任意单束正前回波差、重复旧帧和发布时刻不能冒充独立测得速度或停距。

前进1580起步、1570巡航、最低1550继续作为用户指定的车辆输出范围。正常接近可采用1570→1565→1560→1555→1550的下降候选，各档何时切换由实时剩余预算和已测动态响应决定。1580起步及0.6s保持也要通过整段运动和最终滑停预算，不能无条件压过近目标限速。

预算不足时直接请求1500，不等待整条渐降曲线走完。到1550仍无法满足停距时，应提前中性并停止/报告失败；不得输出1501–1549伪装更低慢速，不自动补1580脉冲逼近目标，不恢复用户已取消的主动反转刹车测试。

## 停车状态与完成条件

正常目标停车依次为：

1. 当前阶段取得真实、有效的目标几何，持续更新短目标和速度/PWM上限。
2. PWM按可执行下降曲线减小，实际运动上界与完整停车包络每拍仍要通过。
3. 电机请求1500，进入滑行阶段；继续依据新鲜可靠点云做受限纠偏，直到可靠判断移动已很小或静止，再回中并锁定。纠偏和回中会改变车体扫掠，必须计入停车包络。
4. 单独检查中性指令采用与物理停稳证据。软件锁定、串口交付成功或1500本身不能证明车辆静止；点云失效时报告运动未知，不能偷偷开始停车计时。
5. 对斑马线，只有完整车体在线前、位置/朝向合格且可靠反馈满足停稳门，才由不同新鲜位姿的源时钟连续累计至少3秒。重新移动则清零重计，完成后才推进第一桶。

“移动很小后回中锁定”是执行收尾条件；赛事3秒计时仍须满足经标定的停稳判据。原生任务用 `|速度| + |角速度|×车体半径` 约束任一角点运动，不能只看车体中心平移。

正常停车保留上述滑行监督；人工急停、失联、非法/旧指令及底层故障立即中性、回中、锁存，优先于正常纠偏和任务计时。观测失效不得持续尝试转向或自动重新解锁。两种停止都不能通过软件状态宣称已物理停稳。

任务阶段和目标身份只由真实完成事件推进：斑马线完成→第一桶正确半圈/出口→第二桶→灯前区域停车及有效绿灯→终点整车入区停稳。保存run、阶段revision、实例ID和完成账本；旧元素重现可继续作为障碍或定位证据，不能重启上一阶段。阶段切换撤销旧路线和晚到结果，同时保留实际速度/转向历史用于停车检查。[在线任务接口](在线元素驱动任务.md)

## 当前能力与明天验收边界

当前实际部署仍为单类 `blue_cone` 模型，不能声称它已识别斑马线/红绿灯。完整Rust任务/导航是离线仿真链，尚未接入当前实车PWM直道执行链；既有米制速度与减速度都是明确标注的模拟值，不可直接复制到车辆。当前底盘映射也只支持未经验证的模拟预览。[底盘标定映射](底盘标定映射.md)

PWM与实际速度、降档迟滞、1500落地滑行距离/时间、滑行中纠偏/回中响应尚未标定；相机地面矩阵、完整车身/车头外参、里程计质量与误差、源时钟及MCU接收/失联停车仍需实物证据。架空回1500后很快停转不能替代这些测量。
