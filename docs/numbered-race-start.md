# 比赛启动命令

在车上的 Bash 终端使用 `start_程序号_最大等灯秒数`。程序 1 取自当天实跑的 y114／219，程序 2 取自 y115／220 建图版。两套实际执行程序均使用 N10P、460800 baud 和现有 N10P 安装标定。当前编号程序使用 Rust V4L2 相机和灯珠识别。

| 命令 | 作用 |
| --- | --- |
| `start_1_7` | 运行现场版，本轮灯区最长等待 7 秒 |
| `start_2_12` | 运行建图版，本轮灯区最长等待 12 秒 |
| `start_1_7 --show` | 回读实际选中的版本、视觉后端、可执行文件和秒数 |
| `start_2_12 --check-only` | 运行相机、雷达和 ROS 2 启动检查，电机保持锁定 |
| `start_1_7 --status`、`start_1_7 --stop` | 查看或停止当前共享的比赛服务 |

1、2 号以终点直道内侧隔板开口为灯架。沿行驶方向，光电线位于灯架上游 1.00 米。车端按雷达几何估算前轮首次穿过这条线的时刻，开始计算命令里的秒数。车头目标距灯架约 0.55 米，后缘须完全越过光电线，在区内确认停稳。从过线起采集的两帧新鲜有效绿灯可在停稳后放行，无有效绿灯时按过线倒计时放行。即使秒数为 0 或计时已在进区途中结束，也先完成区内停车。秒数可为非负整数或小数，仅对本轮生效。

编号入口把选定的程序和秒数带过后台 systemd 单元，直到实际控制进程。同一个可执行文件派生本轮 ROS 2 控制和雷达进程。短命令直接使用 Rust 相机。旧命令的 `--profile mix`、`dark`、`light` 参数兼容，实际后端统一回报 `rust`。

## 安装

程序 1 现由分支 `race/program1-y114-crosswalk` 维护。最初的赛场版本标签为 `race-program1-y114-wait-20261121`，以 `41337e1` 为直接父提交。程序 2 在主分支上继续维护。两套分别使用 ROS 2 构建参数交叉编译，并用 `scripts/inspect_elf.py` 的 `ros2-humble` 配置检查 ELF。主机工具 `scripts/install-numbered-programs.py` 接收两个已编译的 ELF 和各自源提交，安装到车上的版本目录，以单个符号链接切换编号入口。

车上 Bash 配置负责识别命令名，两份启动配置分别记录硬件桥、相机与程序身份。已开的终端可直接通过 PATH 使用 0–60 的整数秒组合，重新加载 `~/.bashrc` 或新开终端支持其余非负秒数。桌面 `Rust` 文件夹单独保存 N10 交付源码。
