# 4、5 号视觉建图版

4 号从 2 号比赛程序派生。5 号从 3 号独立保守版派生，正向 PWM 沿用 1560 上限。两版 N10P 均为 460800。分别用 `start_4_7 --show`、`start_5_7 --show` 查看版本及本轮等灯秒数。整数或小数秒沿用原编号入口语法。`--check-only` 运行锁定的相机、雷达和底盘检查。

- 采集进程用 Rust 读取 V4L2 的 640×480 MJPEG 帧，保留单调时钟的采集时刻。斑马线、灯色、挡板及锥桶检测使用同一相机帧。启动与 ROS 发现并行，真实底盘和雷达就绪后，已有条纹定位可提前发车，缺少条纹定位则沿用 3 秒放行逻辑。灯区沿用两帧新鲜绿灯与命令的最长等待时间。
- 蓝挡板用跨列连续的蓝板和金属下沿定位。可见方向的真实雷达点为同一板面提供距离，标定相机的边缘用于延伸到本帧缺束的角度。首桶为红色，第二桶为蓝色。蓝桶轮廓还结合挡板上沿的遮挡和底座形状。在当前赛段、颜色、测绘坐标和连续图像一致时，锥桶才参与地图辅助。只有视觉方位时，沿视线的深度来自已有地图，而非新测距离。
- 补充点独立于原始雷达。相机来源、投影时刻、补点数量和位置纠正轴记录在 `camera_ground`，帧级像素观测保存在 `run/camera-ground.jsonl`。真实 8 cm 门、Guard、端线回退及光电线上游补进仍用既有比赛控制逻辑。
- 编号安装器 `scripts/install-vision-programs.py` 只接收交叉编译的 4、5 号 ELF，把两版放进单独的 `vision-current` 发布目录。两版启动配置只需相机设备和运行路径。备份、1–3 号的发布目录与车桌面源码独立保存。
