红绿灯沿用原来的信号判断和 10 s 规则。两轴实测定位与灯架距离吻合时，车辆可松开原有单次制动滑入停车区。若已停在光电线上游，使用已有的起步与滚动指令完成同一个灯区停车，再进入原有等待。终点先尝试原端线与端墙测距回退，缺失或明显将挡板推到测绘边界之外时，地图距离可以用于原有制动。原有静止观察仍需从多帧真实点云确认。

## 随机 IMU 突变
