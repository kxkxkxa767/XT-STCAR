## 输入与范围

规则来源：工程内 2026 年 8 月初稿 PDF，第 3、4、5、8 页。外场长 5–8 m、宽 4–6 m，两段直道各自 3–6 m、宽各 1–2 m。不是两段直道没有长度范围，也不是把区域内部长度等同于从车初始位置到出口的距离。

新增 `SweepScene` 原生 Rust 入口，分别接入外场尺寸、两段直道长度/宽度、两桶实测位置、横道位置、灯红时长、可选内挡板和可选视觉可见区域。长度/宽度不会传给控制器作为隐藏地图；同一默认控制器运行所有场景，真值仅用于传感器渲染、物理检查和独立裁判。无需旧固定路线多边形可行才允许构造场景，但保留规则测量校验和实际几何冲突检查。

本批是有限网格，**不代表连续范围内所有实数位置都通过**：

- 外场长、宽与两段直道长、宽共六轴，0.5 m 网格：15,435 个原始尺寸组合。
- 每个尺寸组合分别测试无内挡板/有内挡板，同步/异步两种模式。不兼容组合如直道长超过外场、锥桶撞墙，明确记录 `input_incompatible`，不计作完赛，也不宣称物理不可能。
- 两桶距左右侧 1–3 m、左桶距上侧 2–3 m，以 0.5 m 网格在标准场地另扫 75 个组合；这还不是九轴全笛卡尔积。
- 另测横道近/中/远、3/5/10 秒红灯、0/±2 mm/±3 cm 均匀有界量程扰动；真实噪声分布尚未标定。
- 对识别区、3 m 距离和 150° 水平视野的限制是单独假设测试，不代表实际镜头已标定。
- 含初始冒烟测试并去重，共 **62,026 个作业**；构造拒绝和实际运行次数分开统计。

图示识别区边界不证明存在实体挡板。`corridor_walls=true` 明确模拟厚 20 mm 的两段内挡板；雷达做胶囊线段求交，物理检查用完整旋转车身与挡板距离，异步和同步均检查中间运动。独立绕桶裁判、停车时间、零速结束、速度/净空约束和 180 秒原有工程上限未放宽。

非桶仍是理想语义与理想定位，桶全程零视觉，仅依靠真实原生雷达检测链。这不是实际 YOLO 图像泛化验收、主机实时性测试或实车放行。

## 使用

在工程根目录：

```bash
python3 scripts/local-sim-sweep.py status --out work/local-sweep-20261003/round-02
```

停止时对 `process.json` 中工作进程发送 TERM；正在进行的两场可能留下中断证据。之后同一命令续跑：

```bash
python3 scripts/local-sim-sweep.py run --out work/local-sweep-20261003/round-02
```

单工作进程文件锁避免重复调度；中断中的 `running` 会在重启时重新排队。已完成证据不会重跑覆盖；若要改模型/控制器或参数，建新批次。

可分批运行 `--limit 100`。空闲磁盘低于 10 GiB 暂停并保留证据。防休眠只在当前后台任务存活时有效，合盖或关机仍可能中断，应保持插电和开盖。

```bash
cargo run --release --locked --offline -p xt-stcar-robot-runner --example lidar_sweep -- example
cargo run --release --locked --offline -p xt-stcar-robot-runner --example lidar_sweep -- sync input.json evidence-dir
```
