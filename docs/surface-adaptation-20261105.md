# y57 在线等效负载与 PWM 渐变补偿

使用者要求从第一段斑马线前的动力响应判断当前场地的阻力，过线后继续修正后续 PWM，变化应平顺。本轮只在 Mac 开发和仿真，没有操作车辆。车上最近实跑仍为 y54／引擎 161；y57／164 为待测候选。

## 实现

独立 Rust 模块 `route-engine/src/race_surface.rs` 保存本轮等效额外负载，单位 m/s²。带动力时用「该实际 PWM、当前速度下的基准加速度 − IMU 实际加速度」更新；滑行时用有效雷达滑行拟合，尚无拟合时用 IMU 积分差的减速度。基准动力表来自 y53 拟合、y54 留出验证，完整参数及局限见 `surface-simulation-20261105.md`。

这个量包含地面滚动阻力、电池、传动等变化，无法凭单段速度分离纯地面摩擦。户外跑道的轮胎附着可能更高，滚动阻力和附着系数仍须分开处理。

每个新雷达序号最多学习一次，使用桥返回的实际 PWM。相邻 IMU 积分窗口须完整落在该档执行器稳定之后；低速、急转或档位切换的窗口不参与辨识，原控制器继续运行。负载以 1 s 时间常数滤波；停车等待不会积累一次大的更新。斑马线后统一使用从静止锚定的车体纵向 IMU 速度，不能把转弯时后墙的轴向投影速度当作车速。

原阶段控制器选择基础档位，补偿模块按基准动力曲线反查最接近的现有档位。只在斑马线放行后到第二桶出弯之间的持续前进档 1550–1590 上补偿，每次最多 5 PWM、最快每 0.25 s 一步。速度暂缺时以相同速率退回补偿。原先 1600 起步／加速、1500 收油和 1300 刹车即时执行；平滑只针对新增补偿，原有控制器的档位切换保留。

第一桶接近段和两桶过渡段的收油预算同时计入当前／下一步补偿的余推。灯区和终点各自保留原控制，没有把它们的参数或状态复用于此模块。学习状态为固定大小，查表最多九档，不加线程或车端拟合任务。实车 CPU 和 IMU 长时间误差尚未测量。

反馈字段 `surface_response` 给出负载、最新残差、学习次数、来源和当前补偿。起步前仍只学习，不补偿第一段；本轮不解决高阻力下第一段停得偏远的问题。

## 离线结果

六个情境分别开启／关闭补偿，共十二次。关闭方式仅在离线驱动器中每拍清空学习状态，两边使用同一份控制代码、物理模型和随机种子 1。基准布局 8×4 m，附着系数情境参数 0.6。增加阻力会同时降低同 PWM 下的加速度、稳态速度及滑行距离。`plant.resistance_steps` 只修改物理世界，不给控制器提供真实阻力。

| 阻力情境 | 关闭补偿 | 开启补偿 | 开启后的独立任务判定 |
| --- | ---: | ---: | --- |
| 恒定 1.00 倍 | 21.18 s | 20.88 s | 通过 |
| 恒定 1.25 倍 | 23.68 s | 22.68 s | 通过 |
| 恒定 1.50 倍 | 24.98 s | 26.38 s | 未通过：终点车尾在区外约 4.6 cm |
| 恒定 2.00 倍 | 超时 | 超时 | 灯区入口未完成 |
| 第 8 s 从 1.00 → 1.50 | 24.98 s | 24.28 s | 通过 |
| 第 8 s 从 1.50 → 1.00 | 近障停车 | 24.18 s | 未通过：未完成灯前停车 |

秒数是模型首次运动至终点事件扣红灯等待，**失败行的秒数不代表有效完赛**。十二次均未出现物理接触。恒定 1.5 倍时，两桶末端从 17.0 s 提前到 16.2 s，灯区停车也完成，但未修改的终点控制最终停短。这一情境的整圈表现比关闭补偿差，不能只报告前半段提速。高阻力切回低阻力的灯区失效也仍须处理。

动态估计确实发生：第 8 s 阻力上升的情境，斑马线等待时额外负载约 0.010，第二桶末端约 0.203 m/s²，补偿最高 15 PWM。反向切换时，估计由约 0.241 降到 0.098 m/s²，第二桶末端补偿为 5 PWM。滤波不是立即收敛，弯中不拿横向运动更新负载。高阻力情境实际额外负载是 0.287 m/s²，当前短直道估计存在滞后。

这些结果支持该模块能够从行驶响应学习并渐变补偿，尚不支持室外整圈可靠性或实车提速结论。模型使用理想语义相机，动力表部分档位仍为外推，终点位置存在约 0.33 m 的既有建模残差，IMU 输入亦比实车理想。不能按仿真调到通过就声称真实地面已验证。

原件：`work/y57-surface-adapt-qVP3cmba/final-v4`。精简配置与结果：`docs/surface-adaptation-20261105.json`。早期中间方案在 `pairs`、`pairs-v2`、`final`，不作为最终结果。

## 复现

```sh
cargo build --release --manifest-path tools/scan-geometry/Cargo.toml --example surface_sim
tools/scan-geometry/target/release/examples/surface_sim config/surface-sim-20261105.json work/new-adaptation-run
```

配置 `surface_adaptation: false` 运行同源码的无补偿对照。配置 `plant.resistance_steps: [[8, 1.5]]` 在第 8 秒切换阻力；初始阻力仍由 `plant.resistance_scale` 指定。

标准检查：Mac release 构建、968 项 Python／Rust 参考回归、9 项 Rust 测试通过，clippy 维持原有 32 条警告。车用包提交另记于本轮机器记录。
