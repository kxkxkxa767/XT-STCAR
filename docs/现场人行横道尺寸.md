# 现场人行横道尺寸

2026-09-23用户提供当前地面人行横道规格。A4纸按标准210 × 297毫米换算；本记录是现场尺寸参照，不是图像测量结果。

| 项目 | 数值 | 来源 |
| --- | --- | --- |
| 单条白条长边 | 297 mm（29.7 cm） | A4纸长边 |
| 单条白条短边 | 105 mm（10.5 cm） | A4纸短边的一半 |
| 相邻白条边缘净间距 | 108 mm（10.8 cm） | 用户现场提供 |
| 短边方向重复节距 | 213 mm（21.3 cm） | 105 + 108；假设相邻条纹沿短边方向并排 |

单条长宽比约2.829；上述并排方式下，间隙/条宽比约1.029。若有N条等宽并排白条，总跨度为 `N×105 + (N−1)×108` 毫米。条数及长边相对车辆方向尚未确认，不据此指定车前/车侧方向或整个人行横道范围。

当前 `crates/robot-core/src/field.rs` 的规则场地模板间隙为105毫米，与本次现场108毫米相差3毫米；模板维持原规则来源，不能把它当作这块实物的精确尺寸。当前视觉白条检测使用图像几何及间隙比例范围，并无可直接写入的“实物条长/条宽/间隙”三项参数；现有默认间隙/条宽范围0.25–3.0包含本次1.029，但这不证明实物已能识别。

本次只记录尺寸，不改检测阈值、相机内外参、导航配置，不发车辆控制命令。后续可以将这些已知尺寸用于相机画面对照和地面投影核验；单凭纸条规格不能完成相机标定。
