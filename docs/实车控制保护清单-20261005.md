## B：驾驶台与串口桥的基础保护

| 编号 | 条件 | 作用 |
| --- | --- | --- |
| B1 | Rust桥300 ms无有效指令 | 电机/舵机回1500并锁定 |
| B2 | 驾驶台所有者350 ms无请求 | 释放所有者，请求停止 |
| B3 | 指令时标超前、龄期>=250 ms、序号逆序/重复 | 拒绝旧指令并锁定 |
| B4 | Rust控制循环间隔>150 ms或时钟倒退 | 回中并锁定 |
| B5 | 手动模式相机/雷达>=1s；自动模式按A4/A5持续质量恢复；底盘>=200ms或采集进程报错 | 保留底层异常立即锁定；自动感知迟帧不再被通用健康检查提前锁定 |
| B6 | 上电、服务启动/重启默认锁定；停后必须显式重新启动 | 禁止恢复网络后自行继续跑 |
| B7 | boot、epoch、run_id及所有者匹配 | 防急停/接管之后旧自动请求重新生效 |
| B8 | 人工急停优先，人工接管取消自动会话 | 自动不能顶掉人工停止；接管后再次点击才手动解锁 |
| B9 | 全链只一个串口所有者；核对/dev/car与/dev/laser实际设备且拒绝争用 | 防两个程序交替控制底盘或打开错误设备 |
| B10 | 电机1350–1620（未启用倒车时下限1500）、舵机1350–1650 | 非法PWM立即锁定；网页四项设置另有方向范围 |
| B11 | 无解锁不能drive；解锁时必须中性、使用停止后的新时标 | 防旧解锁请求迟到启动 |
| B12 | 手动控制页失焦、隐藏、关闭、状态样本>250 ms或网络出错 | 当前控制页请求停止；只读观察页不因此停别人的控制 |
| B13 | 串口输入EOF/非法JSON/过长行/队列满、输出状态背压、写串口出错 | 锁定或结束并尝试补发20帧中性；不保证硬件故障时停车 |
| B14 | HTTP令牌、来源校验、请求体<=2048字节及并发上限 | 防误调用/资源耗尽；不是赛道停车条件 |

网页停止按钮/空格、终端stop都请求全局停止。CLI退出只比较并取消自己的自动会话，
不能停止接管后的新手动控制。静止观测不是制动距离或实际车速标定。

## C：仍在离线比赛算法中、当前不会控制车端的检查

- 位姿、扫描、相机、语义时间戳/坐标系/质量/租期与地面投影一致性。
- 车体足迹、障碍膨胀、轨迹中间姿态碰撞、曲率/速度/加速度与制动包络。
- 规划节点/算时/终端预算、到达容差、停稳条件、普通停车超时。
- 比赛元素顺序、重复身份排除、两桶半圈与出口朝向、灯/斑马线/终点规则。
- 最终采用时的命令、任务revision与执行状态再次检查；模拟参数/配置有效性。

这些不能全部压成“低置信度就停车”；每个参数以实际使用的配置为准。
当前没有在实车启用C组，取消C组检查也不能解决A8造成的这次预检拒绝。
