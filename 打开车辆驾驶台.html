XT-STCAR 驾驶台

在这台 Mac 上输入 ssh xt-stcar 或 ssh bianbu@192.168.0.156 连接车辆，两种方式都会建立 CPE 网页转发。然后打开下方驾驶台。

需要自动连接并打开时，双击同文件夹里的 打开车辆驾驶台.command；它也能补齐已有 SSH 连接的网页转发。

使用已建立的 SSH 网页转发。打开页面不会自动解锁。

本机地址 127.0.0.1 通过 SSH 连接到车上，车辆的局域网监听地址变化不影响这个入口。

SSH 已连接，但网页打不开或要求访问码？

新的别名和直接 IP 登录都已配置自动网页转发。若当前连接是在更新配置前建立的，或网页需要访问码，双击工程内的 打开车辆驾驶台.command，或者在 Mac 本地终端（提示符为 yuhaojin@…）运行：

python3 /Users/yuhaojin/Documents/XT-STCAR/scripts/open-vehicle-console.py --link cpe

命令会复用 CPE 的 SSH 连接、建立网页转发并自动带上访问码打开驾驶台。

HTML 本身不能执行 SSH 命令。本文件不保存密码或访问码。
